# Telas da Rottava

Cada arquivo é uma tela funcional. Campos, estados, ações e ligações estão dentro dele. Categorias, marcas e buscas reutilizam a mesma tela de catálogo. Autenticação da equipe reutiliza o padrão visual do login, com autorização própria.
